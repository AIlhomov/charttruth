# AI development disclosure

**Tool used:** OpenAI Codex, an AI coding assistant, in the Codex desktop application.

**Role:** Assisted with official-rule/reference research, original interface design, application code, classical image-processing algorithms, OCR integration, test implementation, browser inspection, debugging and submission-document drafts. The human entrant must review the work and supply accurate team/contribution details before submission.

**Runtime:** No generative model or LLM analyzes user charts. Runtime image understanding uses the existing Tesseract English LSTM OCR model plus original deterministic pixel processing, regression and validation. No model was trained or fine-tuned for this project. No paid inference service or private API credential is required.

**Assets:** Three synthetic sample charts are generated by original chart-drawing code from explicit numeric specifications. They are illustrative data, not real-world evidence. The logo and interface styling are original code. Inter/Manrope fonts and Lucide icons are attributed third-party resources. No AI image generator, reference screenshot or competitor sample image was used in the final product.

**Originality boundary:** Existing research repositories and the design gallery in the parent workspace were inspected for concepts and constraints. Their application code and artwork were not incorporated. All original ChartTruth implementation, tests, samples and documentation were created on 10–11 October 2026 within the published competition period. Existing open-source libraries and the pre-trained OCR model are separately credited.

This disclosure should be included in the Devpost submission and the YouTube description. Amend it if additional human or AI tools are used after this build; do not claim this is a complete history of later work.

**Validation and demo additions:** Codex also assisted the external Misviz stress-test harness, reliability fixes, demo recording automation and narration copy. The optional voice preview uses **Microsoft Zira Desktop**, offline synthetic text-to-speech through Windows System.Speech; it is not a recording of the entrant's voice. Playwright captures actual application interactions; FFmpeg encodes the video and captions. No analysis result, progress screen or successful export was substituted for actual behavior. External images are credited in the evaluation manifest; they are not added to the runtime sample gallery.
